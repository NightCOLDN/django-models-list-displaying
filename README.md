# Онлайн-библиотека с каталогом книг (models_list_displaying)

Учебный проект по работе с базами данных, моделями и кастомной пагинацией в веб-фреймворке Django.

## Структура проекта

```text
library_project/
├── .gigaide/             # Настройки проекта среды GIGA IDE CE
├── books/                # Django-приложение для работы с книгами
│   ├── migration/        # Миграции базы данных
│   ├── templates/        # HTML-шаблоны приложения
│   │   └── books/
│   │       ├── books_list.html     # Шаблон общего каталога
│   │       └── books_by_date.html  # Шаблон страницы конкретной даты
│   ├── admin.py          # Конфигурация панели администратора
│   ├── apps.py           # Настройки приложения
│   ├── models.py         # Модель Книги (Book) с полями name, author, pub_date
│   └── views.py          # Логика фильтрации книг и умной пагинации по датам
├── fixtures/             # Начальные данные для базы данных
│   └── books.json        # Набор тестовых книг от Нетологии
├── main/                 # Главный конфигурационный каталог проекта
│   ├── settings.py       # Основные настройки проекта (включая STATICFILES_DIRS)
│   └── urls.py           # Главный файл маршрутизации (подключает books.urls)
├── static/               # Статические файлы (CSS, стили разметки Нетологии)
│   └── css/
│       └── styles.css    # Файл кастомных стилей отображения плитки
├── venv/                 # Виртуальное окружение Python (изолированное)
├── .gitignore            # Файл исключений для Git (игнорирует venv, db, .gigaide)
├── db.sqlite3            # Локальная база данных SQLite
├── manage.py             # Скрипт управления Django-проектом
└── requirements.txt      # Список зависимостей проекта
```

## Функционал и особенности логики
1. **Общий каталог (`/books/`):** Отображает все доступные в базе книги в виде горизонтальной адаптивной сетки плиток.
2. **Фильтрация по датам (`/books/<pub_date>/`):** Выводит книги, опубликованные строго в указанный день.
3. **Умная пагинация по дням:** Кнопки навигации `<` и `>` внизу страницы ведут не на соседние дни календаря, а динамически вычисляют по базе данных ближайший *предыдущий* и *следующий* дни, в которые была опубликована хотя бы одна книга.
4. **Формат дат:** Вывод дат в шаблонах принудительно переведен в строгий цифровой формат `YYYY-MM-DD`.

## Инструкция по запуску

1. Активируйте виртуальное окружение.
2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Примените миграции к базе данных:
   ```bash
   python manage.py migrate
   ```
4. Загрузите демонстрационный набор книг из фикстуры:
   ```bash
   python manage.py loaddata fixtures/books.json
   ```
5. Запустите локальный веб-сервер:
   ```bash
   python manage.py runserver
   ```
6. Откройте в браузере страницу: [http://127.0.0](http://127.0.0)
